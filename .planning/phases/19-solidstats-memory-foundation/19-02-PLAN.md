# Plan 19-02: Author the Isolated Runtime Boundary

## Objective

Add validation-ready Kubernetes, edge, monitoring, backup, and deploy artifacts
without applying them or inventing unverified values.

## Tasks

### Task 1: Namespace, identity, workload, and storage

Under `k8s/memory/`, add operator-bootstrap namespace/RBAC, separate
ServiceAccounts, Qdrant StatefulSet and private Service, MemPalace Deployment and
ClusterIP Service, separate PVCs, probes, resources, and hardened contexts.
Pin Qdrant to the verified v1.19.0 unprivileged digest. Keep the MemPalace image
as a validator-rejected placeholder until the local build produces a digest.

### Task 2: Network isolation

Add default-deny ingress/egress plus DNS, MemPalace-to-Qdrant, Prometheus scrape,
and host-nginx-to-MCP policies. The host-source placeholder must fail validation
until a kube-router probe supplies the actual source CIDR.

### Task 3: Backup and monitoring

Add a suspended-by-default snapshot CronJob that calls the Qdrant collection
snapshot API and packages MemPalace metadata, manifest, and checksums under
`backups/solidstats-memory/`. Collection name, upload image, and credentials
remain fail-closed gates. Add only verified static scrape targets and health
alerts; metric-name alerts wait for an observed metrics surface.

### Task 4: Independent deploy path

Add a dedicated secret renderer, namespace-scoped CI identity, deploy workflow,
and validator. CI excludes operator-bootstrap resources, refuses placeholders,
checks namespace/resource/security/storage/network rules, and has no permissions
in staging or observability namespaces.

### Task 5: Public edge preparation

Add an idempotent host-nginx template for HTTPS `/solidstats/mcp` only. Preserve
path and streaming semantics, pass Authorization, disable buffering, and resolve
the ClusterIP at operator bootstrap. Do not install, reload nginx, request a
certificate, or change DNS during autonomous execution.

## Operator Gates

- Supply immutable MemPalace local-build image digest.
- Measure host source under kube-router and local corpus/PVC requirements.
- Source-review the transform and record the embedding strategy evidence without
  selecting vector reuse or re-embedding in advance.
- Confirm collection naming, metrics endpoint, and backup uploader contract.
- Explicitly authorize repository application of Kubernetes/RBAC/nginx files;
  the current execution environment rejected these persistent security-boundary
  mutations before file creation.

## Verification

Run manifest parsing, namespace/RBAC/policy/security validators, secret scans,
workflow lint, nginx static validation in an isolated prefix, and server-side
dry-run only after the operator supplies a clean test cluster/context.
