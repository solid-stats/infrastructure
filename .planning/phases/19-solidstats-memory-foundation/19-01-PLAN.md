# Plan 19-01: Freeze the Repository Migration Contract

## Objective

Make the accepted migration decisions executable as a versioned policy and an
offline bundle validator before any workload or real data is touched.

## Tasks

### Task 1: Commit the migration policy

Encode the exact active rooms, archive wings, `SolidStats` common wing, frozen-write
attestation, disabled semantic/KG/diary/auto-capture features, capture record
shape, local parallel-import mode, and exact-ID deletion gate.

### Task 2: Validate policy and bundles offline

Validate policy invariants. When passed `--bundle`, require `manifest.json`
with Chroma source, Qdrant target, frozen writes, safe relative paths, SHA-256
checksums, and evidence that embedding strategy/model/version/dimension, corpus
checksum, and parity evaluation were recorded. The validator verifies packaging,
not the still-unverified cross-backend record transform or strategy quality.

### Task 3: Test fail-closed behavior

Cover the committed policy, forbidden feature enablement, checksum mismatch,
and directory traversal. Tests use only the Python standard library.

## Verification

```sh
python3 scripts/validate-solidstats-memory-policy.py
python3 -m unittest tests/test-solidstats-memory-policy.py
```

## Done When

The accepted policy is machine-readable, invalid drift fails loudly, and a
future offline bundle cannot pass without frozen-write, embedding-evidence, and
complete-checksum attestations.
