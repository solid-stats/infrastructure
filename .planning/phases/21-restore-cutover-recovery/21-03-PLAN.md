## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Operator journal -> remote SSH batch | Local acknowledged state must survive disconnects and govern resume/rollback. |
| Qdrant alias pre-state -> atomic alias action | Concurrent operator changes can invalidate the planned target. |
| Host nginx -> MemPalace ClusterIP | The only public route crosses host and Kubernetes network boundaries. |
| Public client -> MCP token/session/tools | Untrusted HTTP input reaches authenticated protocol methods. |
| Cutover script -> machine-local MCP config | Exact client registration changes local developer state. |
