## ASVS level 2 trust boundaries

| Boundary | Untrusted input | Required control |
| --- | --- | --- |
| Frozen snapshot to inventory CLI | Paths, symlinks, files, Chroma rows, metadata, documents, vectors | Resolve and contain paths, reject links/special files, strict lossless schema, bounded pagination and allocation |
| v3.5.0 oracle to inventory CLI | Source checkout/import path and derived identity values | Approved exact-version artifact, containment, version/provenance check, no dynamic install |
| Inventory CLI to private output/logs | Corpus-bearing output and attacker-controlled strings | Private root only, canonical encoding, redacted diagnostics, no shell interpolation, secret scan |

## STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation plan |
| --- | --- | --- | --- | --- | --- |
| T-20-02-01 | Tampering | Snapshot traversal | high | mitigate | Block execution until resolved paths are contained and every component is non-symlink and regular |
| T-20-02-02 | Tampering | Record serialization | high | mitigate | Reject lossy metadata, missing bytes, duplicate IDs, and field coercion; compare canonical digests |
| T-20-02-03 | Information disclosure | Outputs and diagnostics | high | mitigate | Private output root, value-free errors, secret-name rejection, and tests over captured logs |
| T-20-02-04 | Denial of service | Pagination and record decoding | high | mitigate | Enforce page, record, byte, depth, query, top-k, and elapsed-work bounds before processing |
| T-20-02-05 | Elevation of privilege | External command invocation | medium | mitigate | Use fixed executable plus argument arrays, no shell, controlled environment, and timeout |
| T-20-02-06 | Repudiation | Source evidence | medium | mitigate | Canonical manifest with checksums, counts, oracle provenance, freeze attestation digest, and timestamps |

All high-severity mitigations are blocking acceptance conditions under ASVS level 2.
